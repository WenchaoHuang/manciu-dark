# Changelog

All notable changes to Manciu Dark will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [0.2.0] - 2026-10-26

### Added

- HTML tag and attribute highlighting.
- Markdown scope tuning and USD keyword highlighting.

### Changed

- Refined C++, Python, CMake, and JSON syntax highlighting.
- Expanded the README with language support, a color palette, semantic
  highlighting settings, and local packaging instructions.

## [0.0.1] - 2026-08-25

### Added

- Initial release of the Manciu Dark color theme.
- Semantic highlighting for types, functions, variables, parameters, and
  related symbols.
- TextMate scope tuning for C/C++, Python, CMake, CUDA, JSON, YAML, TOML, XML,
  and LaTeX.
